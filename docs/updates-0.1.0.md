# 百面相 0.1.0 内测版

- **视**查看人物、关系、参与事务和所在圈层。头像会参考已有性格，首次选定后沿用。
- **听**看场外人物最近发生的事，展开同一事务的前情。完整结束的线收在「余音」。
- **味**看社交圈近来的公开气氛、缘由和变化。圈名、成员可以编辑，也可以删除圈子。
- **嗅**收录世界里的公开消息。可以手动新增，也可以为当前聊天开启定时出稿。六个文件夹共用毛玻璃外观，稿件按载体排版。

在酒馆扩展页用仓库地址安装百面相。先装好千千结和白鳥数据后端，打开聊天，在「设置 → 通用设置 → API 配置」选择主、副模型，再点「世界观」里的「百相流转」。已有底账的常规流转使用副模型更新「味」、主模型推进「听」。

安装步骤与依赖说明见[百面相仓库](https://github.com/atonal519/ST-Polyphony#安装内测版)。
